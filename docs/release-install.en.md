# Install LDOS from a Release

[简体中文](release-install.md)

Linux x86_64 and Windows x86_64 packages are currently available. Python, Node.js, and Rust are not required.

Download the package for your platform from [LDOS Releases](https://github.com/KKKneko/LDOS/releases/latest).

## Linux

On Debian or Ubuntu, download the `.deb` package:

```bash
sudo apt install ./LDOS_*_amd64.deb
```

On other distributions with AppImage support, download the `.AppImage` package:

```bash
chmod +x LDOS_*_amd64.AppImage
./LDOS_*_amd64.AppImage
```

## Windows

Download `LDOS_*_x64-setup.exe`, run the installer, and then launch **LDOS** from the Start menu.
